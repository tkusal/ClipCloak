# clipcloak-vscode

## 1.0.0

### Major Changes

- 🎉 Official 1.0.0 Stable Release

  - **CLI**: Full scanner with `--staged` and `--format sarif` support.
  - **Desktop**: Cross-platform background clipboard monitoring with interactive notifications and Safe Paste (`Ctrl+Shift+V`).
  - **VS Code**: Real-time IDE integration underlining sensitive data as you type.
  - **Integrations**: Native git `pre-commit` hook and Claude Code MCP agent interception.
  - **Core Engine**: High-performance, memory-safe detection with Shannon Entropy and false-positive elimination.
  - **Packs**: Comprehensive support for AWS, GitHub, Stripe, JWT, Network, Brazil (CPF/CNPJ/Pix), and EU (IBAN/VAT) secrets.
